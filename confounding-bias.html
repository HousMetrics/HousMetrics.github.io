Confounding Bias

A simple exploration of how causal relationships can be reasoned about, how confounding can distort interpretation, and how linear regression can be used to estimate effects more carefully.

Why Causal Inference Matters

In machine learning, a linear regression model can be used to predict data points when the data is assumed to have a linear trend. Another use case is to determine whether a relationship between two variables is actually causal. Understanding causality requires thinking carefully about the data-generating process, not just the correlations we observe.

Variable
─────→
Outcome

A direct causal relationship can be represented as a simple directional flow from variable to outcome.

In reality, there are often more variables and more intricate complexities lurking around the corner. A classic example is the relationship between a seasonal driver and two observed outcomes that both rise in summer.

Confounding

Consider a situation where a confounder influences both the treatment variable and the outcome. This can make two variables appear strongly related even when one does not directly cause the other.

Variable
─────→
Outcome

The confounder affects both the variable and the outcome, creating a misleading association.

A useful illustration is the example of ice cream sales and shark attacks. Both rise during summer, so the correlation between them may look high even though the underlying causal mechanism is completely different.

Data generating process:
shark_attacks = 3*summer_indicator + epsilon_sharks
ice_cream_sales = 2*summer_indicator + epsilon_sales

Where the last terms of each formula represent the error term. When we receive the data and check the Pearson correlation between shark attacks and ice cream sales it is equal to 92%. So they appear highly correlated.

In this setup, the error terms reflect noise, but the shared seasonal pattern can create a misleadingly high Pearson correlation. If we regress shark attacks on ice cream sales alone, we get:

Naive regression (only ice cream sales):
X = ice_cream_sales.reshape(-1, 1)
y = shark_attacks
model = LinearRegression()
model.fit(X, y)

print("Intercept:", model.intercept_)
print("Slope:", model.coef_[0])
Intercept: 0.31 Slope: 1.29

This can be misleadingly interpreted as "for every ice cream sale there will be 1.29 shark attacks." However, we have seen that the original data explicitly shows that ice cream sales do not cause shark attacks. The true effect is zero!

When we include the confounder (summer indicator) in the model, the estimated relationship changes substantially:

Including the confounder:
X = np.column_stack([ice_cream_sales, summer_indicator])
y = shark_attacks
model = LinearRegression()
model.fit(X, y)

print("Intercept:", model.intercept_)
print("Slope:", model.coef_)
Intercept: 0.22 Slope: [0.03 2.94]

And when we control for the confounder and predict without sales:

Intercept: 0.223 Slope: 3.01

This illustrates a core lesson of causal inference: correlation is not enough; we need to reason about the data-generating process. By accounting for the confounder, we can see that ice cream sales have virtually no effect on shark attacks, and that the summer season is the true driver of both.
